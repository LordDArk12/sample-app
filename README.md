# Sample Web Application with Docker & Bash Automation

Практический проект, демонстрирующий навыки контейнеризации веб-приложений и автоматизации процессов развертывания инфраструктуры.

## 🚀 Основной функционал
* **Backend:** Веб-приложение на Python (`sample_app.py`), использующее шаблонизатор для динамического отображения страниц.
* **Контейнеризация (Docker):** Настроенный `Dockerfile` для сборки легковесного и изолированного образа приложения, готового к деплою.
* **Автоматизация (Bash):** Скрипт автоматизации `sample-app.sh`, который в один клик управляет процессами сборки, запуска контейнеров и проверки их статуса.

## 🛠 Стек технологий
* **Language:** Python
* **DevOps / Infrastructure:** Docker, Bash Scripting, Linux environment
* **Frontend:** HTML/CSS (в папках `templates` и `static`)

## ⚙️ Инструкция по запуску через автоматический скрипт
Чтобы запустить проект и развернуть Docker-контейнер автоматически, выполните скрипт в терминале Linux:
```bash
chmod +x sample-app.sh
./sample-app.sh
